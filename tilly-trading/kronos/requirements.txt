# dependencies beyond what's already above. It intentionally avoids two
# packages that would otherwise be the obvious choice:
#  - PyYAML for config files: no prebuilt wheel yet for very new CPython
#    releases (confirmed against PyPI - not even PyYAML's latest release
#    ships a cp314 wheel for any platform), and no C compiler on the VPS to
#    build one from source. backtest/config.py reads config/*.toml instead,
#    via `tomllib` - standard library since Python 3.11, nothing to install.
#  - matplotlib for report charts: same wheel problem. backtest/charts.py
#    renders its three charts as plain inline SVG instead.
